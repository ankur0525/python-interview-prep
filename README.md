# Python interview prep

`python_questions.pdf` is a set of ~20 common Python interview questions I collected while prepping. `python_questions_copyable.pdf` is the same set but in a version where the text is actually selectable/copyable (the first one is more of a scan/image-based PDF that's annoying to copy code out of).

`Practice.ipynb` is me actually answering those questions - things like reversing a string with slicing, counting vowels, converting strings to Decimal, what `__main__` actually does, etc. Some answers have my own comments explaining why something works, since half the point of doing this was making sure I could explain it out loud in an interview, not just get the right output.

Nothing to install beyond a normal Python 3 + Jupyter setup, all standard library.
